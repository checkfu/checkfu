---
title: "Dashboard"
description: "Browse and edit resources, watch Sessions live, and export agents as code."
---

Open the `Dashboard` URL that `checkfu deploy` prints and sign in with the deployment's `CHECKFU_API_KEY`. Anyone who signs in has full access. Your browser session expires in seven days.

| Section      | What you can do                                                                          |
| :----------- | :--------------------------------------------------------------------------------------- |
| Sessions     | Watch live, send messages, interrupt, allow or deny tool calls, and answer custom tools. |
| Agents       | Create, edit, archive, and **Export as code**.                                           |
| Environments | Edit networking policy and allowed hosts.                                                |
| Automations  | Create, run now, pause, resume, and see runs.                                            |
| Artifacts    | Browse versions and files, create viewing links, publish, and delete.                    |
| Memory       | Create stores and edit memories.                                                         |
| Vaults       | Create vaults and add or replace MCP credentials.                                        |

Use the [CLI](/reference/cli) or [HTTP API](/reference/http-api) for Files and Webhooks.

**Export as code** downloads `agents/<name>.md` and a `checkfu-lock.json`. Unzip it into a project and run `checkfu apply . --dry-run`. See [Agents as code](/guides/agents-as-code).
