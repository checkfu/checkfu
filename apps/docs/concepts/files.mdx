---
title: "Files"
description: "Upload bytes for agents to read, and download the files Sessions produce."
---

A File is an immutable upload or session output with a filename and content type. Once created, its contents never change.

<CodeGroup>

```sh Checkout CLI
checkfu files upload ./report.pdf
checkfu files download --file-id "$FILE_ID" -o report.pdf
```

```sh curl
curl --fail-with-body -X POST "$CHECKFU_BASE_URL/v1/files?filename=report.pdf" \
  -H "Authorization: Bearer $CHECKFU_API_KEY" \
  -H "Content-Type: application/octet-stream" \
  --data-binary @report.pdf

curl --fail-with-body -o report.pdf "$CHECKFU_BASE_URL/v1/files/$FILE_ID/content" \
  -H "Authorization: Bearer $CHECKFU_API_KEY"
```

</CodeGroup>

Use the HTTP commands above with the registry packages `@checkfu/sdk@0.0.1` or `checkfu@0.0.2`. File metadata and byte transfer commands are available in checkout builds on deployments that serve the File endpoints.

## Transfer bytes with a checkout build

A candidate package built from this checkout provides `files.upload` and `files.content` on both SDK clients. Install the candidate tarball from the checkout you are running.

```ts
import Checkfu from "@checkfu/sdk"
import { readFile, writeFile } from "node:fs/promises"

const client = new Checkfu()
try {
	const file = await client.files.upload({
		filename: "report.pdf",
		content_type: "application/pdf",
		body: await readFile("report.pdf"),
	})
	await writeFile("downloaded-report.pdf", await client.files.content(file.id))
} finally {
	await client.close()
}
```

The signed-in dashboard downloads saved Files from the Files panel of the session that captured them.

## Attach a File to a Session

Pass a `file` resource when you create the Session. This example uses a checkout-built SDK:

```ts
import Checkfu, { FileId } from "@checkfu/sdk"

const client = new Checkfu()

const session = await client.waitForPending(
	await client.sessions.create({
		agent: agent.id,
		environment_id: environment.id,
		resources: [{ type: "file", file_id: FileId.make(file.id), mount_path: "q3/report.pdf" }],
	}),
)
```

The agent reads it at `/mnt/session/uploads/q3/report.pdf`. Its file tools can read uploads directly, while `bash` cannot, so the agent copies a File into `/workspace` if it needs to pass it to a shell command.

To reuse a saved File in the dashboard, choose **Use in new session** in the source session’s Files panel. Review the read-only mount and start the new session when you are ready. The new session references the same File.

## Files from Session outputs

When a turn ends with `end_turn`, `budget_reached`, or `refusal`, Checkfu saves each file the agent wrote to `/mnt/session/outputs` as a File (subject to [Session output limits](/reference/limits#session-outputs)). Read the File list with a checkout-built SDK:

```ts
const outputs = await client.sessions.outputs.retrieve(session.id)
for (const file of outputs.files) console.log(file.id, file.filename)
```

For results too large to save as session outputs, have the agent save an [Artifact](/concepts/artifacts) with `save_artifact`.
