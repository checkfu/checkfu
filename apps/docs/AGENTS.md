# AGENTS.md

Mintlify source for `https://docs.checkfu.com`: public documentation for the open-source Checkfu project in this repository.

## Audience and scope

- Readers are developers who deploy Checkfu into their own Cloudflare account (`checkfu deploy`) then build on its API, SDK, CLI, MCP server, and Dashboard.
- There is no shared hosted base URL. Examples use `$CHECKFU_BASE_URL` (the API URL `checkfu deploy` prints, such as `https://<api-worker>.workers.dev`, or `http://localhost:1337` locally, which is the same variable the CLI and SDK read) and `$CHECKFU_API_KEY` (the deployment's single API key).
- Document what this repository serves. Do not describe hosted-only concepts such as Organizations, Workspaces, billing, Budgets, team invites, or per-user API keys.

## Sources of truth

- HTTP contract: `CheckfuApi` in `packages/sdk`, exported to `openapi.json`. `apps/docs/openapi.json` is generated by `bun run generate`; never edit it by hand.
- Behavior: `apps/api`, `packages/domain`, `packages/authoring`, `packages/pi-providers`, `apps/cli`, `apps/mcp`, `alchemy.run.ts`, `.env.example`, and the package READMEs.
- Confirm every endpoint, field, header, event type, limit, CLI flag, and environment variable against the source before documenting it. Leave out anything you cannot confirm.

## Writing rules

- Less is more. Respect the reader's time: follow William Zinsser's _On Writing Well_ (clarity, simplicity, brevity, humanity). Cut clutter, filler intros, and recap outros.
- Show, then tell. Lead with a working code example. No diagrams: clear sentences and code samples only.
- Concept and guide pages leave edge cases, error codes, limits, and optional fields to the reference pages and the generated API reference.
- Lead with what the reader can do, then explain the model.
- Short sentences, active voice, ordinary verbs. Tables for exact lookup, prose for explanation.
- Do not repeat the generated reference under `/api-reference`. Show the fields people use and link to it for the rest.
- Examples must be complete and runnable against a deployment: `curl` with `--fail-with-body`, and TypeScript with `@checkfu/sdk`.
- Use the resource names the API uses: Agent, Environment, Session, Memory store, File, Artifact, Vault, Credential, Automation, Webhook.
- Keep page paths out of `/api` (Mintlify reserves it). Generated OpenAPI pages live under `/api-reference`.
