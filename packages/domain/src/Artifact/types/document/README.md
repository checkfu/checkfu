# Document

A page that shows one Markdown file.

Make an artifact from this type and supply:

- `content.md`: the document. The first `#` heading becomes the page title.
- Any images the document shows, referenced by relative path.

Supported Markdown: headings, paragraphs, bullet and numbered lists, block quotes, fenced code, `***` for a rule, and inline code, bold, italic, links and images. Raw HTML is shown as text.

Do not supply `index.html` or `artifact.json`; they come from the type.
