# Slides

A slide deck written as one Markdown file.

Make an artifact from this type and supply:

- `content.md`: the deck. A line holding only `---` starts a new slide.
- Any images the slides show, referenced by relative path.

Move with the arrow keys, space, or the buttons. The address ends in the slide number, so a link can point at a slide.

Each slide supports the same Markdown as the document type: headings, paragraphs, lists, block quotes, fenced code, and inline code, bold, italic, links and images.

Do not supply `index.html` or `artifact.json`; they come from the type.
